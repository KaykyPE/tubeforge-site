Política de Privacidade

Última atualização: 7 de novembro de 2026

Esta política explica como o aplicativo para computador TubeForge ("app") trata os dados dos usuários, incluindo os dados obtidos das APIs do Google e do YouTube.

1. Onde seus dados ficam

O TubeForge roda inteiramente no seu computador. O app não possui servidores próprios e o desenvolvedor não recebe, não armazena e não tem acesso aos seus dados. Configurações, chaves de API, tokens de acesso e vídeos produzidos ficam salvos apenas no seu computador (pasta %APPDATA%\TubeForge e pasta de Vídeos).

2. Dados do Google que o app acessa

Quando você conecta um canal, o app solicita estas permissões da sua Conta Google:

  • youtube.upload: para enviar ao seu canal os vídeos que você produziu e mandou publicar, com título, descrição, tags, thumbnail e data de agendamento definidos por você.
  • youtube.readonly: para mostrar o nome do canal conectado e estatísticas públicas (inscritos, visualizações e número de vídeos) no painel do app.

Esses dados são usados somente para essas funções, exibidas a você dentro do app. Não são vendidos, compartilhados com terceiros, usados para publicidade nem para treinar modelos de inteligência artificial.

3. Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

4. Serviços de terceiros que você escolhe usar

Algumas funções enviam conteúdo diretamente do seu computador para serviços externos, usando chaves de API que você mesmo cadastra no app:

  • Anthropic (Claude): temas e instruções para gerar roteiros, títulos e descrições.
  • OpenAI: descrições de imagem para gerar thumbnails (opcional).
  • Microsoft Edge TTS: o texto do roteiro, para gerar a narração.
  • Pixabay, Pexels e Openverse: termos de busca, para baixar fotos e vídeos de banco de imagens.
  • YouTube Data API: termos de busca, para pesquisar vídeos públicos.

Os dados da sua Conta Google não são enviados a esses serviços. Cada serviço tem sua própria política de privacidade.

5. Armazenamento, segurança e exclusão

Os tokens de acesso do Google ficam em arquivos no seu computador e são usados só para as funções acima. Para apagar todos os dados do app, exclua a pasta %APPDATA%\TubeForge. Para revogar o acesso do app à sua Conta Google a qualquer momento, acesse myaccount.google.com/permissions.

6. Crianças

O app não é destinado a menores de 13 anos e não coleta intencionalmente dados de crianças.

7. Alterações

Esta política pode ser atualizada. A data no topo indica a versão atual.
